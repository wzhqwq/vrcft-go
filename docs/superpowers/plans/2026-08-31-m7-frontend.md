# M7 Frontend Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (- [ ]) syntax for tracking.

**Goal:** Replace the Wails template with a responsive Chinese desktop control center for runtime status, plugin operations, construction settings, and diagnostics.

**Architecture:** A Svelte 5 shell composes project-owned Tailwind/Bits UI components and three independent typed modules. Runtime, Plugins, and Settings each own one query/event lifecycle behind injectable Wails ports; pages consume view models only. One narrow Go change carries the decoded Avatar name to the Runtime DTO before bindings are regenerated.

**Tech Stack:** Go 1.24, Wails v2.13, Svelte 5, TypeScript, Vite 8, pnpm 11, Tailwind CSS v4, Bits UI, Lucide Svelte, Vitest, Svelte Testing Library, and Playwright.

**Spec:** docs/superpowers/specs/2026-08-31-m7-frontend-design.md

## Global Constraints

- Read the approved spec and docs/project/subsystems/frontend.md before every task.
- Runtime, Plugins, and Settings stay separate; an event re-queries only its owner.
- Pages never import Bits UI or frontend/wailsjs directly.
- M7 v1 is dark-only with semantic tokens and typed Simplified Chinese copy.
- Tailwind uses @tailwindcss/vite and @import "tailwindcss"; no legacy config.
- Shared components are elastic; pages have no horizontal overflow at 640x480.
- At widths >=720px use a left rail; below 720px use a top Tab Bar.
- Settings use explicit componentized forms, local drafts, and explicit save.
- Plugin enable/disable is immediate and isolated by plugin ID; no private config UI.
- Overview shows only the current OSC output target port.
- Run Go commands with absolute repository-local .go-gocache in GOCACHE.
- Use pnpm --dir frontend and keep pnpm-lock.yaml authoritative.
- Use TDD, focused verification, git diff --check, and one commit per task.
- Generate docs/project/status.md only from clean reviewed source.
